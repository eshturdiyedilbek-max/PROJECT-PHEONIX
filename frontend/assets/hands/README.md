# 3D hands (landing hero)

- `left.glb`, `right.glb`: "generic-hand" from WebXR Input Profiles (`@webxr-input-profiles/assets` 1.0.20, npm), MIT License, © 2019 Amazon. See `LICENSE.md`. Unmodified files.
- `still.webp`: a frame rendered from these models by `js/hero-hands.js` (three.js) with both signers at the end of the sign, used only when the browser has no WebGL.

The hands are a 3D render, not footage, and the page says so ("3D" tag and caption).

## The sign

The animation is the **ASL sign WELCOME**, one-handed: the dominant hand in the flat "B" handshape starts about half an arm's length in front of and beside the chest, palm facing across, and sweeps in a large horizontal arc to the centre of the chest, ending palm up. Person A signs it, then person B answers. The bodies (sweaters, cropped at the neck) are simple shapes drawn in code, so the hands have someone to belong to.

Sources: [Lifeprint, ASL University: WELCOME](https://lifeprint.com/asl101/pages-signs/w/welcome.htm); [Wiktionary ASL entry](https://en.wiktionary.com/wiki/OpenB@DistalSideChesthigh-PalmAcross_RoundVert_OpenB@DistalInsideTrunkhigh-PalmUp_RoundHoriz_OpenB@NearCenterTrunkhigh-PalmUp) (start: open B, beside the chest, palm across; end: open B, centre of the chest, palm up).

ASL was chosen because its WELCOME is documented precisely in open sources. A verified Russian Sign Language description of "ДОБРО ПОЖАЛОВАТЬ" was not found.
