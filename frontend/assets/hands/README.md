# 3D hands (landing hero)

- `left.glb`, `right.glb`: "generic-hand" from WebXR Input Profiles (`@webxr-input-profiles/assets` 1.0.20, npm), MIT License, © 2019 Amazon. See `LICENSE.md`. Unmodified files.
- `still.webp`: a frame rendered from these models by `js/hero-hands.js` (three.js) at t = 3.6 s, used only when the browser has no WebGL.

The hands are a 3D render, not footage, and the page says so ("3D" tag and caption).
