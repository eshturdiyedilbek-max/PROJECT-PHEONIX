The Phoenix mark in single-ink SVG. An `<img>` cannot inherit color, so each ink has its own file: choose the file by the ground it sits on. The hex values below are copies of tokens; if a token changes, redraw the file.

| File | Ink | Use on |
| --- | --- | --- |
| `phoenix-mark-ink.svg` | `#121c18` (`ink`, Light) | `surface`, `surface-raised`, `surface-sunken` in the Light theme |
| `phoenix-mark-reversed.svg` | `#eaf0ed` (`ink`, Dark) | the same surfaces in the Dark theme, and on an `accent` fill |
| `phoenix-mark-accent.svg` | `#0e6b4d` (`accent`, Light) | Light surfaces, for one brand moment per view (a splash, an empty state) |
| `phoenix-mark-accent-on-dark.svg` | `#5fd3a1` (`accent`, Dark) | Dark surfaces, same rule |
| `phoenix-app-icon.svg` | white mark on an `accent` tile (`#0e6b4d`), corner radius 22 of 96 | favicon, app icon, avatar. The tile is part of the file; do not wrap other files in a tile |

All marks hold 5:1 or more against the surfaces they are listed for. The mark is a proposal drawn for this system, not an established brand mark.
